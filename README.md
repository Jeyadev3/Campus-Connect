# 🎓 Campus Connect

Campus Connect is a modern College Management System developed using HTML, CSS, JavaScript, and Electron. The application provides a simple and user-friendly interface for managing student information, academic records, and college-related activities through a desktop environment.

---

## 📌 Features

- 📊 Dashboard for quick navigation
- 👨‍🎓 Student Management System
- 📝 Result Management Module
- 💻 Desktop Application using Electron
- 🎨 Modern and responsive user interface
- ⚡ Fast and lightweight application

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Electron
- Node.js

## 🚀 Installation & Setup

### Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/Campus-Connect.git
```

### Navigate to Project Directory

```bash
cd Campus-Connect
```

### Install Dependencies

```bash
npm install
```

### Run the Application

```bash
npm start
```
